# "Cannot read properties of null (reading 'token')" — Render Fix

## Asli wajah (root cause)

Ye error tabhi aata hai jab login request **backend tak sahi se nahi pahunchti** —
response 200 aata hai lekin body khaali/galat hota hai, ya request kabhi backend
tak jaati hi nahi. Sabse common wajah: **Render env vars galat set hai ya set hi
nahi hai**, kyunki `render.yaml` me `VITE_API_URL` aur `CLIENT_URL` dono
`sync: false` hain — matlab ye Render dashboard me **manually** daalne padte hain,
auto set nahi hote.

## Render Dashboard me ye check/set karo

Aapke 2 alag Render services hain:
- `campusfix-api` (backend, Node)
- `campusfix-web` (frontend, static site) → jo `campusfix-app.onrender.com` hai

### 1. Backend service (`campusfix-api`) → Environment tab
```
CLIENT_URL=https://campusfix-app.onrender.com
MONGODB_URI=<aapka real MongoDB Atlas connection string>
JWT_SECRET=<auto-generated, chhedna mat>
```
- `CLIENT_URL` **exactly** frontend ke actual URL se match hona chahiye
  (https, koi trailing slash nahi).
- Agar frontend ka ek se zyada URL hai (custom domain + onrender.com dono),
  comma se separate karo: `CLIENT_URL=https://a.com,https://campusfix-app.onrender.com`

### 2. Frontend service (`campusfix-web`) → Environment tab
```
VITE_API_URL=https://campusfix-api.onrender.com/api
```
- Yaha apne **actual backend service ka URL** daalo (Render dashboard me
  `campusfix-api` service khol ke top pe URL milega), **+ `/api` zaroor lagao**.
- ⚠️ Ye env var sirf **build time** pe use hota hai (Vite). Isko set/change
  karne ke baad **frontend service ko "Manual Deploy" se dubara build/deploy
  karna zaroori hai** — sirf env var save karne se purana build update nahi
  hota.

### 3. Verify karo ki backend actually chal raha hai
Browser me ye URL kholo:
```
https://campusfix-api.onrender.com/api/health
```
Response aana chahiye: `{"ok":true,"database":"connected"}`
- Agar `database: "disconnected"` aaye → MongoDB Atlas me Network Access
  (IP Whitelist) me `0.0.0.0/0` add karo (Render ka IP fix nahi hota).
- Agar page hi load na ho / service sleeping dikhe → Render free tier services
  15 min inactivity ke baad sleep ho jaati hain, pehli request 30-50 sec le
  sakti hai. Thoda wait karke phir try karo.

### 4. Redeploy order
1. Backend env vars set karo → backend redeploy hoga (usually auto)
2. Frontend env var set karo → frontend ko **manually redeploy** karo
   (Render dashboard → campusfix-web → "Manual Deploy" → "Deploy latest commit"
   ya "Clear build cache & deploy")
3. Browser me hard refresh karo (Ctrl+Shift+R) taaki purana cached JS na chale

## Code me kya improve kiya gaya hai (is zip me)

1. `src/lib/api.ts` — Ab agar server se khaali/galat response aaye, error message
   clearly bata dega (e.g. "Could not reach the server at ...", "Server
   returned an empty response") — cryptic `null.token` crash ab nahi aayega.
2. `server/src/index.js` — CORS ab `*.onrender.com` origins ko safety-net ke
   taur pe allow karta hai (agar `CLIENT_URL` galat set ho jaye tab bhi login
   silently fail nahi hoga), aur CORS errors ab JSON me aayenge (HTML error
   page ki jagah), jisse frontend crash nahi karega — sahi error dikhega.

In changes ke baad, agar config sahi hai to login turant kaam karega. Agar
config galat hai, ab crash hone ke bajaye **clear error message** dikhega
jisse pata chal jayega exactly kya galat hai.
