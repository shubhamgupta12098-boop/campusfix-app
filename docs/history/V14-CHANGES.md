# CCMMS Mobile All Roles V14

Changes in this build:
- Student, Admin and Staff remain in one project.
- CCMMS logo is used as the app/favicon/login brand.
- Native select dropdown option surfaces are green instead of white.
- A complaint requires **Photo \*** and **Video \***. Both are mandatory in UI and local database/save layer.
- Student rating save is validated and reflected immediately; Admin Reports/Profile rating entry opens Feedback & Ratings.
- Complaint Detail shows original complaint photo/video plus **Before Photo** and **After Photo** work evidence. Admin and Staff keep their existing work-evidence views; Student now has the same before/after section.
- Before photo is required when staff starts work; after photo is required before completion (existing workflow preserved).
