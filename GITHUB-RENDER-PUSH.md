# GitHub Push + Render Deploy

## First GitHub push

```bash
git init
git add .
git commit -m "CCMMS Render MongoDB mobile build"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

## Later updates

```bash
git add .
git commit -m "Update CCMMS"
git push origin main
```

## Render

Recommended: **New → Blueprint** and select the repository. Render will read `render.yaml`.

Set these secret environment values in Render:

```text
MONGODB_URI = your MongoDB Atlas Drivers URI
ADMIN_EMAIL = your admin email
ADMIN_PASSWORD = a strong admin password
FIREBASE_API_KEY = your Firebase Web API key (optional, for Forgot Password)
```

`JWT_SECRET` is generated by the Blueprint. `MONGODB_DB` defaults to `ccmms`.

After deploy, open:

```text
https://YOUR-SERVICE.onrender.com/api/health
```

Expected JSON contains:

```json
{ "ok": true, "database": "mongodb" }
```

Then open the root service URL for the mobile login page.
