This package contains the updated source code.
The old compiled dist folder was removed intentionally because it did not contain the latest changes.

Run locally:
  npm run install:all
  npm run server       # terminal 1
  npm run dev          # terminal 2

For a production build:
  npm run build

Before starting, create .env and server/.env from their example files and add
your MongoDB, Firebase and JWT settings. See README.md for the full setup.

Note: a fresh dist folder is not included. Build after installing dependencies.
