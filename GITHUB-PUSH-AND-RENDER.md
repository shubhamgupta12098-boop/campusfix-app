# GitHub push + Render deployment

## Push this fixed version

From the project root:

```bash
git add .
git commit -m "Connect CCMMS to production API and Render"
git push origin main
```

## Render

Use a **Web Service** (not Static Site), or choose **New → Blueprint** so Render reads `render.yaml`.

Required secrets in Render Environment:

- `MONGODB_URI`
- `FIREBASE_API_KEY`
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`

`JWT_SECRET` is generated by the included blueprint.

Build command:

```text
npm install --include=dev --no-audit --no-fund && npm run build
```

Start command:

```text
npm start
```

After deployment verify:

- `/api/health`
- `/student/`
- `/admin/`
- `/staff/`

The browser portals use `/api` on the same deployed Render domain. No hardcoded development host is required.
